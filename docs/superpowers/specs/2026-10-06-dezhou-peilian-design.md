# 德州陪练 · 设计说明

日期：2026-10-06
状态：按用户原始需求自主完成设计，假设项见文末

## 1. 这个东西是什么

一个单人德州扑克（无限注，Texas Hold'em）网页游戏，一个 HTML 文件，手机和电脑都能玩。

它不是又一个德州游戏，重点是「陪练」：

- 你和 2 到 5 个电脑对手打现金桌，每一步都有清楚的提示：现在是哪一轮、轮到谁、为什么轮到他、你能做什么、每个动作意味着什么。
- 有一个「发牌员模式」，专门练线下当发牌员时最容易卡壳的地方：谁先行动、这一轮结束没有、下一步该发什么、底池该给谁。
- 有一套轻量奖励：筹码余额、经验等级、成就徽章、每日签到，让一个人玩也有目标。

## 2. 用户的痛点怎么对应

| 用户原话 | 对应功能 |
| --- | --- |
| 有的地方容易卡壳 | 顶部「流程条」随时说明当前轮次、轮到谁、你需要补多少 |
| 线下没有提示 | 教练模式：每个按钮下方一句话解释，并给出建议和理由 |
| 当发牌的人时转不过来 | 发牌员模式：在关键节点让你回答「谁先行动 / 下一步做什么 / 谁赢」，答错就解释 |
| 存储量不要太大 | 单文件，约 150 KB，无图片资源，字体从 CDN 加载并有系统字体回退 |
| 手机和电脑都能玩 | 竖屏横屏两套牌桌布局，发布为 claude.ai 网页，同时给本地文件 |
| 设定奖励机制 | 筹码余额、经验等级、成就、每日签到、统计 |

## 3. 玩法范围

- 无限注德州扑克现金桌，盲注 10 / 20，无前注。
- 玩家：你 + 2 到 5 个对手（默认 5 个，六人桌）。
- 买入 2000（100 个大盲），对手 1500 到 3000 随机。
- 对手打光筹码自动重新买入；你打光筹码可以从余额补买。
- 单挑规则正确：两人时庄家是小盲，翻牌前先行动，翻牌后后行动。
- 最小加注规则正确：加注额至少等于上一次加注的额度；不足额的全下不会重新打开已行动玩家的加注权。
- 边池计算正确，平分底池时多出的筹码给庄家左手第一位赢家。
- 弃牌到最后一人时，未被跟注的部分退回下注者。
- 摊牌顺序：河牌有下注时最后下注者先亮牌，否则庄家左手第一位先亮；为了学习，对手默认全部亮牌。

不做：锦标赛、多桌、联网、真钱。

## 4. 教学层

### 4.1 流程条（始终显示）

一行文字，随状态更新，例如：

- 翻牌前 · 从大盲左边第一位开始 · 轮到 阿强（枪口位）
- 翻牌圈 · 从庄家左边第一位还在牌局里的人开始 · 轮到你（小盲位）
- 你是庄家：小李出小盲 10，美玲出大盲 20，翻牌前从老王开始

点一下流程条，展开这一轮的完整解释。

### 4.2 教练模式（默认开）

- 动作按钮下方一句话：过牌 = 不下注，把行动交给下一位（没人下注时才能过牌）；跟注 = 补到 40；加注 = 至少加到 80。
- 手牌读数：当前最大牌型（两对 A 和 9）与听牌（同花听牌，9 张补牌）。
- 教练建议：一个小标签，例如「建议跟注」，点开看理由：你有顶对，对手下注 40，底池 120，跟注需要约 25% 胜率，顶对通常足够。
- 一轮结束时的短横幅：这一轮结束，所有人下注相等，发转牌。
- 对手风格标签：紧凶、松凶、紧弱、松弱、平衡，并有一句话说明打法。

### 4.3 发牌员模式（默认关）

开启后游戏在四类节点暂停提问，答对继续，答错解释并允许重答，连错两次自动给出正确答案：

1. 发完底牌：翻牌前第一个行动的是谁？（点座位）
2. 每条公共牌街开始：这一轮第一个行动的是谁？（点座位）
3. 一轮下注结束：下一步做什么？选项：发翻牌、发转牌、发河牌、比牌、直接把底池给某人
4. 摊牌：谁赢？（点座位，牌已亮出）

记录正确率和连对次数，有对应成就。

### 4.4 规则速查

一个可随时打开的页面：牌型大小表（配小牌面示例）、行动顺序图（翻牌前与翻牌后）、盲注、最小加注、边池、摊牌顺序，以及常见卡壳点问答。

## 5. 奖励机制

- 筹码余额：初始 10000，离开牌桌时把桌上筹码结算回余额。余额不足买入时领取救济金 2000，并计入「破产次数」。
- 每日签到：每天首次打开 +500。
- 经验与等级：每手 +10，赢一手 +25，摊牌赢 +50，发牌员答对 +5。等级称号：新手、常客、牌手、老手、高手、牌王。升级解锁桌布颜色（绿、蓝、红、紫）和三种牌背。
- 成就（每个带筹码奖励）：首胜、同花、葫芦、四条、同花顺、皇家同花顺、偷盲成功、诈唬成功、全下获胜、大底池（超过 100 个大盲）、三连胜、翻倍离场、发牌员十连对、河牌逆转。
- 统计：手数、胜率、入池率、最大底池、最佳牌型、发牌员正确率。

## 6. 界面

单屏应用，三段：顶部流程条，中间牌桌，底部你的手牌与动作区。

- 牌桌是椭圆绒布，座位沿椭圆分布，你永远在底部中央。竖屏时椭圆竖长，横屏和桌面时椭圆横长。
- 座位：名字、筹码、位置标签（庄 / 小盲 / 大盲 / 枪口 / 中位 / 关煞）、本轮下注、动作气泡（加注到 60），轮到谁谁有金色描边。
- 桌中央：公共牌、底池、边池、轮次名。
- 底部：你的两张牌放大显示，牌型读数，动作栏：弃牌、过牌或跟注、加注。加注面板有滑杆和快捷档：最小、半池、四分之三池、一池、全下，确认按钮写明「加注到 180」。
- 发牌员记录：右侧抽屉（手机上为底部抽屉），按发牌员口吻逐条记录整手牌。
- 一手结束：结果层显示赢家、牌型、赢得金额，5 秒后自动开下一手，可点击立即开始，也可在设置里关掉自动。
- 单一深色主题：绒布绿为主色，金色只用于轮到谁、庄家按钮和主要按钮描边，牌面是米白纸色。
- 字体：牌面点数和筹码数字用 Bricolage Grotesque，中文界面用系统中文字体栈，数字等宽对齐。
- 音效：Web Audio 合成的发牌、筹码、过牌敲击、赢牌四种短音，可关。
- 动效只有三种：发牌滑入、筹码滑向底池、赢家金色描边。遵守减少动态效果的系统设置。

## 7. 技术架构

```
德州陪练/
  index.html            开发入口，引用 src 下文件
  src/tokens.css        设计令牌（颜色、字体、间距、动效）
  src/styles.css        界面样式
  src/engine.js         规则引擎：牌、牌型评估、一手牌状态机、边池、摊牌（无 DOM）
  src/ai.js             对手决策
  src/coach.js          教学层：局面解释、建议、听牌、发牌员提问
  src/narrate.js        引擎事件转中文发牌员记录
  src/app.js            界面、动画、音效、本地存储、奖励
  test/*.test.js        node --test，覆盖引擎
  build.js              合成单文件到 dist/
  tools/serve.js        本地静态预览
  dist/德州陪练.html     独立单文件（本地打开即玩）
  dist/artifact.html    发布到 claude.ai 的版本（无 doctype 外壳）
```

### 7.1 引擎接口

- `new Game({players, blinds, rng})`
- `startHand()`：移动庄家按钮、收盲注、发底牌，返回事件数组
- `legalActions(seat)`：`{fold, check, call, raise:{min,max}, allIn}`
- `act(seat, {type, amount})`：执行一个动作，返回事件数组；不自动进入下一街
- `nextStep()`：描述下一步该做什么（发翻牌、发转牌、发河牌、比牌、无人跟注直接给底池、继续本轮下注及首个行动者），供发牌员模式提问
- `advance()`：执行 `nextStep()` 描述的那一步，返回事件数组
- 事件类型：button、blind、deal-hole、street、action、round-end、deal-board、showdown、award、returned、hand-end、bust、rebuy

引擎只产生结构化事件，中文文案在 `narrate.js` 里生成。

### 7.2 牌型评估

七张牌枚举 21 种五张组合，取最大。单个五张组合的分值 = 牌型等级与关键点数按 15 进制编码，可直接比较。返回牌型等级、中文名、最佳五张（用于高亮）。

### 7.3 对手决策

- 翻牌前：Chen 公式打分，按位置、人数、是否面对加注调整门槛；性格参数（松紧、凶弱）平移门槛和加注概率。
- 翻牌后：把成牌按相对公共牌的强度分档（高牌、对子、顶对、超对、两对、三条、顺子、同花、葫芦、四条、同花顺），加上听牌补牌数估算胜率，与底池赔率比较决定弃牌、跟注、下注或加注，带少量随机和诈唬概率。
- 下注尺度：翻牌前开池 2.5 到 3 个大盲，翻牌后半池到四分之三池，按小盲取整。

### 7.4 存储

`localStorage` 一个键，存余额、经验、成就、统计、设置、最近签到日期、牌桌筹码快照（每手开始时保存，中途刷新按上一手开始时的筹码恢复）。所有读写包在 try/catch 里，读不到就按新用户处理。

## 8. 测试

`node --test test/`，覆盖：

- 十种牌型的识别与中文名
- 踢脚、A2345 轮子顺、同花比较、七张取最优
- 翻牌前从大盲左边开始、大盲有选择权；翻牌后从庄家左边开始；单挑顺序
- 最小加注；不足额全下不重新打开加注权
- 弃到最后一人退回未跟注部分
- 三人不同全下量的边池分配；平分底池零头归属
- 庄家按钮跳过没筹码的座位

## 10. 自主决定的假设

用户不在线，以下按最合理方式决定，都可以改：

- 现金桌而不是锦标赛（更适合反复练流程）
- 六人桌默认，可在大厅选 3 到 6 人
- 对手默认在摊牌时全部亮牌（学习优先）
- 教练模式默认开，发牌员模式默认关
- 四色牌（方块蓝、梅花绿）作为可选项，默认关，因为线下用的是真牌
- 界面全部中文，扑克术语用国内常用说法：翻牌前、翻牌圈、转牌圈、河牌圈、过牌、跟注、加注、弃牌、全下、庄位、小盲、大盲、枪口位、中位、关煞位
