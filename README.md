# 德州陪练

单人德州扑克练习游戏，一个 HTML 文件，手机和电脑都能玩。

重点不是赢钱，是把流程练熟：每一步都说明轮到谁、为什么、能做什么；发牌员模式在关键节点先问你该怎么做。

## 怎么玩

在线：https://sidbaobao.github.io/dezhou-peilian/ ，手机和电脑浏览器直接打开。iPhone 用 Safari 打开后「添加到主屏幕」会像应用一样全屏。

本地：直接打开 `dist/德州陪练.html`，不需要联网（联网时会加载一款更好看的数字字体，没有也不影响）。

## 功能

- 无限注现金桌，盲注 10 / 20，买入 2,000，对手 2 到 5 个，五种打法风格
- 规则完整：单挑盲注、最小加注、不足额全下、边池、平分零头、摊牌顺序
- 教练模式：顶部流程条、按钮下的一句话解释、建议和理由、手牌读数与听牌
- 发牌员模式：谁先行动、下一步做什么、谁赢，答错给解释
- 奖励：筹码余额、每日签到、经验等级与解锁、15 个成就、统计
- 规则速查：牌型表、流程表、动作说明、边池、常见卡壳问答

## 开发

```
node --test test/*.test.js     # 引擎、教学层、对手决策的测试
node tools/serve.js 8765       # 本地预览 http://localhost:8765/
node build.js                  # 合成 dist/德州陪练.html 与 dist/artifact.html
```

源码在 `src/`：`engine.js` 规则引擎、`coach.js` 教学层、`ai.js` 对手决策、`narrate.js` 发牌员记录、`app.js` 界面。设计说明在 `docs/superpowers/specs/`。

数据只存在浏览器本地（localStorage），换设备不会同步。
